# PromptGuard: AI Validation & Security Layer 🛡️

PromptGuard is a robust data-sanitization engine built with **Pydantic V2**. It acts as a professional "Quality Control" gatekeeper between raw user input and Large Language Models (LLMs), ensuring every request is cost-optimized, secure, and perfectly formatted.

## 🚀 The Problem vs. The Solution
* **The Problem:** Raw API data is often "messy" (inconsistent naming), unvalidated (incorrect temperature settings), and potentially insecure (privacy leaks).
* **The Solution:** PromptGuard uses advanced Pydantic features to clean, validate, and secure data before it reaches your AI agents.

## ✨ Key Features
- **Smart Data Mapping:** Uses `Field` aliases to automatically translate messy external keys (e.g., `u_id`) into clean, standardized internal names (`user_id`).
- **Safety Guardrails:** Implemented a `model_validator` that acts as a security check—preventing private prompts from being stored in public cloud paths.
- **Cost & Performance Control:** Enforces strict range constraints on AI parameters like `temperature` and `max_tokens` to prevent API errors and over-billing.
- **Business Intelligence:** Leverages `@computed_field` to automatically categorize prompt complexity (Low/Medium/High) based on real-time word count.

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Core Library:** Pydantic V2
- **Data Format:** JSON Serialization
